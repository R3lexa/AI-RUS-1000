# AI-RUS-1000

**«РУСЬ ЗА 1000 ЛЕТ»** — AI-сериал для TikTok: вся история как гонка счётчиков.
Одна серия = одна эпоха, 60–75 секунд. 862 → 1991, 8 серий.

Хук сериала: «В год 900 Москвы не было. Через 1000 лет — 1/6 суши.
Это история о том, как так вышло».

Производство полностью на AI (пайплайн проекта [AI-TOK](https://github.com/R3lexa/AI-TOK),
та же студия, что [СТАРТАП ЗА 300 РУБЛЕЙ](https://github.com/R3lexa/AI-STARTUP-300)):
сценарий → озвучка ElevenLabs → мошн-графика Remotion → рендер. Без камеры, без монтажа.

**Счётчики в каждой серии:** `ГОД · НАСЕЛЕНИЕ ≈ · КТО ГЛАВНЫЙ` — числа = сериал.

**Достоверность:** даты — по летописям; оценки помечены «≈» и «по оценкам»;
легенды помечаем «по легенде». Никакой политики после 1991 в сезоне 1.

## Структура эпизода

```
episode-01-prizvanie/
  SCRIPT.md      — сценарий и раскадровка
  tools/         — генераторы: озвучка (ElevenLabs Chris), SFX (numpy)
  remotion/      — проект рендера (1080×1920, 30 fps)
  assets/        — vo/ (озвучка), sfx/ (звуки), tts-cache/
  final/         — готовый mp4
```

## Голос

**ElevenLabs Chris** («Charming, Down-to-Earth»), модель `eleven_multilingual_v2`,
естественный темп, без ускорения. Караоке-сабтитры синхронизируются из
character alignment автоматически.

Ключ API передаётся переменной окружения `ELEVENLABS_API_KEY` и никогда не коммитится.

## Пересборка эпизода

```bash
cd episode-01-prizvanie
ELEVENLABS_API_KEY=sk_... python3 tools/gen-vo.py      # озвучка + timeline.json
python3 tools/gen-audio.py                              # SFX
cp -r assets/vo assets/sfx remotion/public/assets/      # синк аудио
cd remotion && npx remotion render Main out/episode-01.mp4
```
