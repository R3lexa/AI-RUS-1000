# AI-RUS-1000

**«ТЁМНАЯ РУСЬ»** — AI-сериал для TikTok: одна тёмная история с лицом и
ставками в каждой серии. 862 → 1991, 8 серий, 60–70 секунд.

Хук сериала: «Ей предложили выйти замуж — за убийцу мужа. Она сказала: да» —
in medias res, лицо в кадре с 0.0 секунды (ресёрч хуков: лицо в первые 2 с =
+44% вовлечённости; 70–85% удержания на 3 с → ×2.2 просмотров).

Производство полностью на AI (пайплайн [AI-TOK](https://github.com/R3lexa/AI-TOK),
та же студия, что [СТАРТАП ЗА 300 РУБЛЕЙ](https://github.com/R3lexa/AI-STARTUP-300)):
сценарий → озвучка → мошн-графика Remotion → рендер. Без камеры, без монтажа.

## Серия 1: три хука для A/B-теста

| Вариант | Хук (первая секунда) | Стратегия |
|---------|----------------------|-----------|
| **A** (основной) | «Ей предложили выйти замуж — за убийцу мужа. Она сказала: да.» | in medias res |
| **B** | «Она сожгла целый город. Из-за трёх голубей.» | шок-деталь |
| **C** | «Убийцы мужа сделали ей предложение. Через год от них ничего не осталось.» | приговор |

Тест: по одному посту в день в одно время, сравнить 3-секундное удержание.

## Структура эпизода

```
episode-01-start/
  SCRIPT.md      — сценарий и раскадровка (v3)
  tools/         — gen-vo.py (edge-tts / ElevenLabs), gen-audio.py (SFX)
  remotion/      — рендер; src/Faces.tsx (SVG-лица), Objects.tsx (драккар,
                  баня, голуби, город), Overlays.tsx (сцены), timelines/ (A/B/C)
  assets/        — vo/, sfx/, tts-cache/
  final/         — готовые mp4 (A/B/C, loudnorm TP −1.5 dB)
```

## Голос

- **Сейчас (бесплатно):** edge-tts, `ru-RU-DmitryNeural`, rate +30%,
  тайминги из SentenceBoundary + atempo-дожим. `python3 tools/gen-vo.py`
- **После пополнения квоты ElevenLabs:** `VO_PROVIDER=elevenlabs
  ELEVENLABS_API_KEY=… python3 tools/gen-vo.py` — вернётся Chris
  (eleven_multilingual_v2), тайминги пересоберутся сами.

Ключи передаются переменными окружения и никогда не коммитятся.

## Пересборка

```bash
cd episode-01-start
python3 tools/gen-vo.py                                   # озвучка + timeline-A/B/C
python3 tools/gen-audio.py                                # SFX
cp -r assets/vo assets/sfx remotion/public/assets/
cd remotion
cp src/timelines/timeline-A.json src/timeline.json        # вариант A/B/C
npx remotion render Main out/episode-01-A.mp4
ffmpeg -i out/episode-01-A.mp4 -c:v copy -af "loudnorm=I=-16:TP=-1.5:LRA=9" \
  -ar 48000 -b:a 192k ../final/episode-01-A.mp4
```
